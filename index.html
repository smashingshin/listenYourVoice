마이크가 안 잡힐 때 — 순서대로 확인
  • ① 주소가 https:// 또는 localhost 인가 — 파일을 더블클릭해 file://로 열면 Chrome이 마이크를 아예 차단합니다. 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000으로 접속하세요.
  • ② 주소창 자물쇠 아이콘 → 마이크 가 '차단'이면 '허용'으로 바꾸고 새로고침하세요. 한 번 거부하면 다음부터 팝업이 안 뜹니다.
  • ③ 다른 앱이 마이크를 쓰는 중인가 — Zoom·Teams·Discord·OBS가 켜져 있으면 Windows에서 장치를 독점할 수 있습니다. 종료 후 재시도하세요.
  • ④ 노트북 하드웨어 뮤트 — F4/F8 등 마이크 뮤트키, 또는 Windows 설정 → 시스템 → 소리 → 입력에서 볼륨이 0인지 확인하세요.
  • ⑤ 장치를 바꿔 보세요 — 목록에 '통신용 기본 장치'와 '마이크 배열' 등이 따로 뜨는데, 하나가 실패해도 다른 쪽은 되는 경우가 많습니다.
  • ⑥ '제약 없이 열기(호환 모드)' 를 켜고 다시 시도 — 에코 제거·노이즈 억제를 지원하지 않는 드라이버에서 OverconstrainedError가 날 때 해결됩니다.
